DocKit 1.1.2：修复版本。界面与功能不变，失败时的提示更清楚，并修正 PowerPoint 规范化后打开的是备份的问题。

修复：

- PowerPoint（.pptx）规范化完成后，结果里列出的是未修改的 .backup 备份；现在列出并打开规范化后的文件。
- 损坏的 Word/Excel/PowerPoint 文件以前只显示「处理失败(详见日志)」，现在直接说明「文件已损坏或不是有效的 Office 文档」；同一批里其他文件照常处理。
- 输出文件夹没有写权限时，以前显示英文系统错误，现在提示换一个可写的位置。
- 格式转换没选目标格式等参数错误，现在在创建输出文件夹之前就拒绝，不再留下只装着副本的空任务文件夹。

内部：新增固定验收脚本（功能、故障恢复、隐私、界面自检）；界面自检在屏幕外运行，不会弹出窗口或占用鼠标键盘。

DocKit 1.1.2: a fix release. Interface and features are unchanged.

- Normalising a .pptx now returns the normalised file instead of the untouched .backup.
- Corrupt Office files report "the file is damaged or not a valid Office document"; other files in the batch still run.
- An unwritable output folder gets a plain message asking for a writable location.
- Invalid arguments (e.g. conversion without a target format) are rejected before any output folder is created.
- Internal: fixed acceptance scripts and an offscreen in-process UI self-test.
